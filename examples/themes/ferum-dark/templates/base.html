{# Ferum Dark — base.html ────────────────────────────────────────────────────────────────────────────── Overrides the default base.html with forced dark mode. WHY THIS FILE EXISTS ────────────────────────────────────────────────────────────────────────────── The default base.html hardcodes data-bs-theme="auto" (follows system preference). To force dark mode we must override base.html and use {{ theme_bs_theme }}, which is injected by render_with_theme() from the "color_scheme" field in theme.json. theme.json → "color_scheme": "dark" → startup.rs reads it into active_theme_color_scheme_cache → render_with_theme() injects theme_bs_theme = "dark" into every page context → this template renders data-bs-theme="{{ theme_bs_theme }}" TEMPLATE INHERITANCE ────────────────────────────────────────────────────────────────────────────── Page templates in the DEFAULT theme extend "default/templates/base.html". This base.html is only used by page templates that THIS theme provides explicitly. Pages not overridden by ferum-dark fall through to the parent chain automatically: render_with_theme() tries "ferum-dark/templates/X", then "default/templates/X".
